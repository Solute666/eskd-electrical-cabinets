# Публикация в каталоге ChatGPT/Codex

Этот документ относится к версии 0.1.0. Репозиторий содержит пакет для установки из GitHub. Он ещё не зарегистрирован в общем каталоге OpenAI, а имя подтверждённого издателя не задано. Подготовка структуры пакета и успешные местные проверки не означают одобрение каталога.

## Что подготовлено

- Самодостаточный навык в `plugins/eskd-electrical-cabinets/skills/eskd-electrical-cabinets`.
- `plugin.json` с версией, описанием и ссылкой на репозиторий.
- Каталог репозитория `.agents/plugins/marketplace.json`.
- Скрипт `tools/build_plugin.py` для сборки ZIP без истории Git и временных файлов.
- Вымышленный пример, средства проверки и перечень зависимостей.

## Действия владельца

1. Проверить установку на целевом клиенте и выполнить первый запрос из README. Сохранить вывод проверки и результат PDF.
2. Выбрать условия распространения авторских материалов. После решения добавить соответствующий файл лицензии и поле `license` в манифест; лицензии сторонних компонентов сохраняются отдельно.
3. В кабинете OpenAI выбрать организацию и проект, пройти проверку физического лица или компании для публикации. У владельца организации есть право отправки; другим участникам может понадобиться разрешение Apps Management Write.
4. Указать в `extensions.com.openai.interface.developerName` фактически подтверждённое имя издателя. Не подменять его автоматически именем GitHub. Подготовить дополнительные сведения, изображения и действующие публичные ссылки, если их требует форма подачи.
5. Собрать ZIP командой `python tools/build_plugin.py`. Открыть раздел Plugins в кабинете OpenAI, загрузить пакет и проверить замечания в Metadata & Skills.
6. Исправить обязательные замечания, загрузить обновлённый пакет и отправить заявку на рассмотрение. После одобрения отдельно опубликовать.

Для текущего пакета не нужен отдельный сервер MCP: в нём только навык и локальные инструменты. Возможность выполнения Python и установки зависимостей зависит от среды запуска. Общая публикация не заменяет проверку поведения в ChatGPT и Codex.

## Проверка перед отправкой

Проверить весь состав пакета, текст и метаданные PDF, лицензию шрифтов, относительные пути и отсутствие данных реальных заказчиков. Публиковать текущую папку навыка с чистой историей, не переносить историю личного репозитория навыков.

Запустить команды проверки и воспроизведения из README. Для дополнительного поиска известных частных названий использовать включённый `audit_package.py` на папке плагина, передав владельческие шаблоны через `--forbidden`. Сам список частных названий не добавлять в публичные файлы. Проверка по заданным шаблонам не заменяет просмотр графики.

## Обновления

После изменений повысить версию в `plugin.json`, выполнить соответствующие проверки и заново собрать архив. Изменения навыков и метаданных в общем каталоге требуют загрузки новой версии ZIP; отправка изменений в GitHub сама по себе не обновляет опубликованный там пакет.

Официальные источники: [упаковка](https://developers.openai.com/plugins/build/plugins), [отправка и публикация](https://developers.openai.com/plugins/deploy/submission). Проверено 11 октября 2026 года; требования формы подачи имеют приоритет при последующих изменениях платформы.
