# Принятые решения оформления

Использовать эти правила при новых задачах. Конкретные модели, закупки и номиналы предыдущего объекта не являются настройками навыка.

| Ситуация | Решение |
|---|---|
| Нужна прежняя ясность при новом составе | Сохранить оформление и обновить электрическое содержание; не откатывать состав. |
| Разная форма клемм | Управление - окружности; силовые и обзорные листы - прямоугольники. |
| Короткие местные шлейфы | Не добавлять вымышленные распределительные группы. Проверить допустимые проводники в зажиме. |
| Зигзаги и подписи далеко от провода | Короткие ортогональные маршруты, подпись у своего отрезка. |
| Лист уже принят | Править локально; сравнить все неизменённые страницы. |
| Неясные названия входов/выходов | DI/DO/AI/AO с однократным пояснением. |
| Разный стиль ПЛК и модулей | Входы слева, выходы справа; функции около проводов, адрес отдельно. |
| Повторяющиеся заводские выводы | Уникальный внутренний идентификатор с физическим местом; заводскую надпись не менять. |
| Маркировка до местной клеммы | Внешний кабель и жила до клеммы, локальный номер после. |
| Ссылки смешаны с обозначением катушки | Позиция отдельно; ссылка под символом, когда она полезна. |
| Не виден источник из другого шкафа | Явная граница, удалённая клемма, кабель/жила, местная клемма. |
| Нужно показать все клеммы | Полный обзор, включая внутренние группы, PE/N, резервы и реальный числовой порядок XT. |
| Замена аппарата | Проверить колодку, защиту, выводы, габарит, соединения и закупку. |
| Материал из наличия | Сохранить связь в модели; наличие и закупку считать раздельно. |
| Увеличение шкафа | Проверить артикул и фактическую панель; перестроить компоновку, не менять только подпись. |
| Спецификация «просто таблица» | Одна нейтральная таблица без титула, даты, дополнительных листов и нижних комментариев. |
| Монтажная раскладка | Нарисовать рейки и короба; обычный шаг осей коробов 180 мм при достаточных зазорах; увеличить по необходимости. |
| Дверь | Лампы над панелью; аварийный останов внизу при принятой компоновке и проверенной доступности. |
| Сокращение кабельных вводов | Считать кабели по переходам стенок, а не жилы; уплотнение и объединение через коробку - разные изменения. |

Не закреплять отклонённые предложения, технические допущения и ранние варианты как требования пользователя.
