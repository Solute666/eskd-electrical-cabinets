# Указатель проектного образца X2002

Основной визуальный образец — `assets/x2002-reference/documents/`. Это комплект до замены покупного шкафа оператора на самодельный: Э3 Р27, монтаж Р31, ПЭ3 Р29, спецификация 12.10.2026. Точные файлы, редакции и хеши: `assets/x2002-reference/set-manifest.json`. Сначала прочитать [границы образца](sample-scope.md).

## Просмотр и проверка

```bash
python scripts/render_reference.py assets/x2002-reference/documents/X2002_ШС1_Э3_Р27_Комплект.pdf --pages 2,3,10 --out WORK/qa/reference
python scripts/render_reference.py assets/x2002-reference/documents/X2002_ШС1_Монтажная_схема_Р31.pdf --pages 1,2 --out WORK/qa/mount-reference
python scripts/verify_reference_set.py assets/x2002-reference --report WORK/qa/reference-set.json
```

После просмотра листа целиком увеличить нужный участок. Не судить о компоновке только по извлечённому тексту.

## Исходники и редакции

Пути относительно `assets/x2002-reference`: `model/mount_model_R29.json` — состав, соединения, клеммы; `model/layout_positions_R31.json` — последние координаты; `model/cabinet_R29.json` — корпус и плата.

Архивы `sources` сохраняют исторические зависимости. Выпуском считать документы реестра. Старые `spec_R18`, `build_mount.py`, `build_customer.py` и базовые PDF не являются актуальной закупкой/компоновкой. Точки воспроизведения: Э3 — `build.py`; силовая панель — `build_r31.py`; поставка — её отдельный исходник Р31. Работать в распакованной копии.

Команды `python scripts/rebuild_reference.py --part electrical --out WORK/rebuild-e3` и `--part mounting --out WORK/rebuild-mount` запускают соответствующую сборку и сравнивают PDF с образцом. Монтажный исходник Р31 строит лист 1, страницы 2–12 переносит из базового PDF. Нативные исходники всех монтажных страниц в этом архиве отсутствуют; не обещать их полную регенерацию из модели.

Разные редакции допустимы: Р30/Р31 меняли координаты, состав и закупка Р29 сохранялись. Перечень поставки отдельно синхронизирован 13.10.2026 при сборке образца; не выдавать его за ранее выпущенный файл.
